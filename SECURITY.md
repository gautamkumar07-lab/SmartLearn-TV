# Security Policy

## Supported Versions
SmartLearn TV actively maintains the latest production releases.

| Version | Supported          |
| ------- | ------------------ |
| 2.4.x   | :white_check_mark: |
| < 2.4   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in SmartLearn TV, please report it privately:
- Email: security@smartlearntv.amazon.edu (or open a private security advisory on GitHub).
- Do not disclose issues publicly until they have been addressed and patched.
